# 门店葡萄酒采购与库存：期初录入和差异排查管理员指引

## 适用范围

本指引适用于 2026 年 1 月起使用系统后，仍需在葡萄酒供应商累计采购和酒款累计采购中补录系统启用前历史金额的管理员。**供应商初始累计**与**酒款初始累计**是两个独立的报表期初视图；两者不要求相等，不会互相覆盖，也不应被相加为一笔新的采购成本。

> 历史期初用于补齐累计阅读，不替代实际采购流水；本月进货、库存成本、付款与月结仍以真实采购记录为准。

## 一、录入前准备

| 检查项 | 操作 | 通过标准 |
|---|---|---|
| 月份 | 在葡萄酒工作台选择当前业务月份 | 不在已经关闭月份直接改历史数据 |
| 供应商档案 | 在“采购管理”确认供应商名称、联系方式和排序 | 不新建近似重复供应商 |
| 酒款档案 | 确认需要补录的酒款已链接正确葡萄酒档案 | 中英文主档和供应商渠道可追溯 |
| 凭据 | 整理系统启用前的发票、对账单或手工汇总 | 每一笔期初都能写清依据与原因 |

## 二、供应商初始累计录入

在“葡萄酒 → 总结 → 供应商月度与累计进货”找到对应供应商，点击“编辑初始累计”。第一次从 **¥0** 修改为历史累计金额时，填写金额、原因和凭据说明。保存后系统应显示该供应商的“真实采购累计”和“期初累计”来源，并在审计记录中保留操作者、时间、修改前后金额与原因。

供应商初始累计用于补齐该供应商在系统启用前的历史采购总额。它不会自动拆分到任何具体酒款，也不会改变库存数量、实际进货单价、付款状态或本月成本。

## 三、酒款初始累计录入

在“葡萄酒 → 总结 → 酒款月度与累计进货”选择对应酒款，使用同样的“编辑初始累计”入口。酒款期初用于补齐该酒款在系统启用前的历史采购累计；可以和供应商期初金额不同，因为二者分别服务于不同的累计报表视图。

不得为了让两个期初总额相同而伪造采购记录。若需要反映历史采购明细，应分别在对应供应商或酒款的期初中录入，并清晰标注依据。

## 四、每月对账与月结

月结前，应在“当月进货”检查本月真实采购。供应商维度的当月金额来自全部采购行；酒款维度只统计已确认链接的采购行。若存在未链接采购，系统应列为“待核对”，而不是自动分配给某款酒。

| 现象 | 优先排查 | 安全修正方式 |
|---|---|---|
| 供应商本月金额高于已链接酒款金额 | 当月是否存在未链接采购 | 从采购行进入人工链接或智能候选；确认后再保存 |
| 供应商与酒款期初金额不同 | 是否误将独立期初当作同一余额 | 无需强行调平；核对各自历史依据即可 |
| 累计金额异常增大 | 是否重复录入期初或重复导入采购 | 查看审计记录和导入批次；使用受控删除/恢复，不直接改存储 |
| 月结后发现期初有误 | 已关闭月份的归档副本是否需要保留 | 新建一笔更正审计并在后续月度调整；不得回写已归档副本 |
| 无法确认酒款链接 | 供应商原名、中文/英文主档与容量年份 | 保持待链接，使用人工链接或新建酒库档案，不按名称猜测 |

月结时系统归档当期的期初基线副本及审计记录。后续修改期初只影响之后的阅读和后续归档，不会静默改变已经关闭月份的历史副本。

## 五、常见操作禁区

管理员不得直接删除采购流水来消除差额，不得为使两个独立期初相同而录入虚假采购，也不得在未核实的情况下把供应商原名自动关联到酒库主档。发生异常时，应保留原始凭据、记录原因并使用系统提供的审计化编辑、恢复或人工链接流程。

## 六、月结前签核清单

- [ ] 已检查当月所有采购行的日期、供应商、金额与原始凭据。
- [ ] 已处理或明确标记所有待链接酒款采购。
- [ ] 已检查供应商和酒款各自期初的最近审计记录。
- [ ] 未把两个独立期初差额当作月结阻断条件。
- [ ] 已确认库存期末盘点完成，且月结后将保留当期快照。
- [ ] 已记录本月需要在下月继续处理的历史凭据或链接异常。
