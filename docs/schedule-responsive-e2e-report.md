# 排班表响应式分页端到端回归报告

**执行时间：** 2026-08-13

**执行命令：** `pnpm test:h5:schedule-correction`

## 范围

本次H5端到端回归针对排班表的外层三页分页与内层“排班表 / 考勤概况”分页，验证实时页宽、缩放后当前页保持、移动端根级溢出和关联核心页面状态。

## 结果

| 验证维度 | 实际结果 |
|---|---|
| 375pt移动端 | 通过；根与body宽度均为375，无横向溢出。 |
| 390pt移动端 | 通过；根与body宽度均为390，无横向溢出。 |
| 430pt移动端 | 通过；根与body宽度均为430，无横向溢出。 |
| 1024px桌面 | 通过；外层排班页、内层排班页和考勤页均与当前页面宽度对齐。 |
| 1280px桌面 | 通过；连续调整后保持排班表当前逻辑页。 |
| 1440px桌面 | 通过；连续调整后保持排班表当前逻辑页。 |
| 排班业务交互 | 通过；编辑模式、排班输入和考勤概况切换未导致错页。 |
| 关联回归 | 绩效汇总、时段成本分析、月度经营报告、个人中心、烈酒库存导入同步和员工档案筛选标签均通过。 |

## 性能与状态同步观察

页宽变化时仅重建当前逻辑页的滚动偏移，使用无动画定位，不触发排班、考勤、薪资或库存重新计算。端到端运行中未出现错误、根级横向溢出或当前页状态丢失。

## 限制

该回归验证浏览器H5布局、分页对齐和业务状态可见性，不等同于真机GPU帧率基准。原生iOS/Android发版前应继续在至少一台真机上检查快速缩放/旋转后的手势惯性体验。
