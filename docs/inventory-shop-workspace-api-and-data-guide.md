# 库存与店铺工作台：接口变更与历史数据处理指南

**适用版本**：库存店铺工作台重构后。

本文说明内部TypeScript接口、Excel导入导出语义、持久化数据处理与废弃接口。项目不暴露新的公共HTTP接口；本文所述均为前端内部状态、组件和导入导出契约。

## 1. 变更摘要

| 范围 | 新契约 | 兼容性影响 |
|---|---|---|
| 十类工作台 | 外层统一管理分类与月份，子页面接收 `month` 与 `embedded` | 独立路由继续可用；嵌入时不再重复安全区、标题或月份导航 |
| 月份状态 | 工作台使用单一受限月份状态 | 分类内旧独立月份状态不再作为可写来源 |
| 移动端布局 | 操作栏使用独立横向滚动与最小44pt按钮 | 不改变业务数据或操作语义 |
| 烈酒台账 | 移动概览与Excel台账并列存在 | 两者读取同一月度数据；视图偏好不参与同步 |
| 分类管理 | 增加排序、原子迁移和安全删除 | 不再允许绕过内容检查直接删除非空分类 |
| 库存预警 | 完全移除 `alertThreshold` 业务字段 | 历史数据加载时自动剥离该字段 |
| 消耗字段 | 消耗瓶数与消耗成本明确分离 | 旧混写数据在加载与同步重载时归一化 |

## 2. 工作台组件契约

所有可嵌入分类页面遵循以下组件接口：

```ts
export interface InventoryWorkspaceScreenProps {
  month?: string;
  embedded?: boolean;
}
```

| 参数 | 含义 | 规则 |
|---|---|---|
| `month` | 外层工作台选定的`YYYY-MM`月份 | 子页面只读取该值，不创建第二个可写月份源 |
| `embedded` | 当前是否由库存/店铺工作台嵌入 | 为`true`时必须使用 `ScreenContainer edges={[]}`，隐藏独立返回导航和重复月份标题 |

通用分类通过`BaseInventoryScreen`使用该契约；烈酒、葡萄酒、食材、设备独立页面也必须遵循同一契约。

## 3. 分类与月份接口

### 3.1 分类顺序

| 工作台 | 固定顺序 |
|---|---|
| 库存 | 烈酒、葡萄酒、水果、食材、啤酒、冰块 |
| 店铺 | 杯具、餐具、日用品、设备 |

库存与店铺使用各自工作台状态。库存分类切换不得改变库存月份；店铺分类切换不得写入库存分类或库存月份。

### 3.2 月份边界

`BoundedMonthNavigator`以全部有效业务月份的并集计算边界：

```text
最早可选月 = 最早有效业务月 - 1个月
最晚可选月 = 最晚有效业务月 + 1个月
```

缓存、路由参数、同步结果和快速选月都必须进入相同的归一化与钳制入口。无有效业务记录时，仅允许当前自然月。

## 4. 烈酒库存台账契约

### 4.1 双视图

| 视图 | 数据源 | 同步语义 |
|---|---|---|
| 移动概览 | 当前月份月度台账 | 业务数据实时反映；仅视图模式为本机偏好 |
| Excel台账 | 同一份月度台账的展示副本 | 排序和筛选不得写回源数组、同步载荷或Excel导出顺序 |

Excel台账固定语义顺序：

```text
序号 → 商品名称 → 参考价 → 期初库存量 → 期初单价 → 期初成本 →
进货数量 → 进货成本 → 期末库存量 → 期末单位成本 → 期末成本 →
消耗瓶数 → 消耗成本 → 集团
```

### 4.2 筛选与排序

筛选引擎只能返回可见行副本。多列筛选按交集计算；合计只汇总可见行。商品名称的中文/英文显示、名称多选、未匹配筛选和排序均属于展示偏好，禁止参与同步。

## 5. 进销存分类管理接口

当前烈酒状态只允许通过以下生命周期语义处理分类：

| 动作 | 约束 |
|---|---|
| 新增/更新 | 创建或更新分类名称、颜色、排序信息 |
| `moveCategory(id, direction)` | 交换相邻分类顺序；`direction`仅可为`up`或`down` |
| `removeCategorySafely(id, toCategory)` | 原子迁移分类内容后删除空分类；目标可为现有分类或`未分类` |

已废弃普通“直接删除分类”与“普通迁移分类”公开路径。调用方不得在界面中自行先删除分类再逐项更新商品，因为会产生孤儿商品与同步中间态。

## 6. Excel导入导出语义

### 6.1 导入

供应商进货表与烈酒盘点导入继续使用原有解析规则。展示列重排、名称中英文显示、排序筛选、集团显示和视图切换不修改Excel原始行、解析映射、匹配结果、金额或库存结算。

烈酒盘点的消耗字段严格区分：

| Excel语义 | 月度台账字段 | 类型 |
|---|---|---|
| 消耗瓶数 | `consumeBottles` | 数量 |
| 消耗成本 | `consumeCost` | 金额 |

禁止将第12列消耗成本写入数量字段，或以一个混合字段兼容两种语义。

### 6.2 导出

Excel导出以源数据和既有字段映射为准。视图排序、筛选、语言切换不重排或修改导出源数组，除非用户在未来明确要求“导出当前筛选结果”。

## 7. 历史数据处理

### 7.1 `alertThreshold`删除

`alertThreshold` 已从运行时库存模型、表单、导入、导出、状态接口、计算和UI删除。历史AsyncStorage或同步返回数据可能仍带有该键；读取时调用单向剥离函数删除该键，随后持久化/同步写回清理后的对象。

```ts
const { alertThreshold: _discarded, ...current } = legacyRecord;
return current;
```

此步骤不应被删除，直到确认所有活跃设备完成一次加载和同步；它不能恢复旧预警功能，也不能将字段重新写入。

### 7.2 消耗字段归一化

历史烈酒台账中可能出现“消耗成本误写入消耗瓶数”。加载和同步重载路径会归一化为独立数量与金额字段，并在后续写回时保持分离。归一化不得改动期初、进货、期末、集团或Excel原始采购记录。

### 7.3 分类排序兼容

旧自定义分类缺少排序字段时，按既有数组顺序补出稳定顺序；无需人工迁移。删除非空分类时必须先选择迁移目标，不能丢弃商品、历史台账、采购记录、集团映射或成本。

## 8. 废弃接口和禁止事项

| 已废弃内容 | 替代方案 |
|---|---|
| 按屏幕宽度自动删除移动概览或Excel台账 | 用户本机切换双视图 |
| `useCompactLedger` | 显式视图偏好状态 |
| 直接删除非空分类 | `removeCategorySafely`原子迁移删除 |
| 普通分类迁移公开接口 | 分类生命周期引擎 |
| `alertThreshold`及低库存预警计算 | 无替代；库存预警已取消 |
| 工作台内重复安全区/标题/月导航 | 由外层工作台唯一提供 |
| “进入烈酒管理/设备管理”中间入口 | 当前分类工作区直接嵌入原有业务页签 |
