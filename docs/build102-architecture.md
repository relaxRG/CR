# Build 102 架构升级方案

## 一、底部 Tab 新结构（5个）

| Tab | 图标 | 原来对应 | 主要内容 |
|-----|------|---------|---------|
| 🍸 鸡尾酒 | `wineglass.fill` | 资料库 (library) | 酒单 / 酒库 / 自制库（保持不变） |
| 🍷 葡萄酒 | `wineglass` | 新建 | 葡萄酒资料库（独立数据，不与鸡尾酒互通） |
| 🔬 研发 | `flask.fill` | 研发 (index/lab) | 计划清单 / 研发计划 / 书库 |
| 🍽 餐食 | `fork.knife` | 新建 | 菜单 / 原料库（独立数据） |
| 🏪 门店 | `building.2` | 门店 (menu/shopping) + 我的 | 在售清单 / 采购清单 / 营业状况 / 备用金 / 经营分析 / 进销存 |

---

## 二、各模块详细结构

### 🍸 鸡尾酒（Tab: cocktail）
- 内部 Segment：酒单 / 酒库 / 自制库
- 数据：沿用现有 `cocktail.recipes` / `cocktail.bottles` / `cocktail.homemade.*`
- **无变化**，仅 Tab 改名

### 🍷 葡萄酒（Tab: wine）
- 内部 Segment：酒款列表 / 产区 / 品种
- 数据键：`wine.bottles.v1`（新建，独立存储）
- 字段：名称(中/英) / 年份 / 产区 / 品种 / 风格(红/白/桃红/起泡/甜) / 酒庄 / 进价 / 售价 / 库存 / 评分 / 笔记 / 照片
- **与鸡尾酒酒库完全隔离**

### 🔬 研发（Tab: lab）
- 内部 Segment：**计划清单** / **研发计划** / **书库**
- **计划清单**（新建）：
  - 鸡尾酒：计划产品列表 + 计划采购清单
  - 餐食：计划产品列表 + 计划采购清单
  - 数据键：`lab.plan.v1`
- **研发计划**（原 lab/index）：
  - 鸡尾酒研发（现有 LabProject 数据）
  - 餐食研发（新增，数据键 `lab.food.v1`）
- **书库**（从原 books Tab 迁移，功能不变）

### 🍽 餐食（Tab: food）
- 内部 Segment：**菜单** / **原料库**
- **菜单**（新建）：菜品列表，含分类/价格/照片/描述
  - 数据键：`food.menu.v1`
- **原料库**（新建）：食材/调料库存
  - 数据键：`food.ingredients.v1`
  - **与鸡尾酒自制库完全隔离**

### 🏪 门店（Tab: store）
- **顶部入口**：「我的」（原 me Tab 内容，折叠为右上角 person 图标或顶部卡片）
- 内部 Segment：在售清单 / 采购清单 / 营业状况 / 备用金 / 经营分析 / 进销存

#### 在售清单
- 子分类：鸡尾酒 / 葡萄酒 / 餐食
- 鸡尾酒：引用 `cocktail.recipes`（只读引用，不复制）
- 葡萄酒：引用 `wine.bottles.v1`
- 餐食：引用 `food.menu.v1`
- 数据键：`store.menu.v1`（存储各品类的在售状态+售价）

#### 采购清单
- 子分类：鸡尾酒 / 葡萄酒 / 餐食
- 每条目：品名 / 规格 / 数量 / 供应商 / 自购链接（可跳转）
- 数据键：`store.shopping.v1`（扩展现有 shopping store）

#### 总营业状况
- 营收记录（按日/周/月）
- 成本项：食材成本 / 烈酒成本 / 葡萄酒成本 / 人工成本 / 房租 / 水电 / 备用金 / 公司运营
- 人工成本可展开：员工列表 / 月出勤 / 工时
- 数据键：`store.revenue.v1`

#### 备用金（A-N 分类）
- A: 食材采购（A1-A10）
- B: 酒水耗材（B1-B3）
- C: 设备工具（C1-C6）
- D: 员工福利（D1-D3）
- E: 营销推广（E1-E3）
- F: 餐具酒具（F1-F6）
- G: 平台推广（G1-G5）
- H: 探店差旅（H1-H3）
- I: 物流运输（I1-I3）
- J: 客户维护（J1-J3）
- K: 日常运营（K1-K9）
- L: 水电费（L1-L2）
- M: 房租（M1-M2）
- N: 备用金账户（N0-N5）
- 数据键：`store.petty.v1`

#### 经营分析
- 经营状况分析（参考美团管家风格）
- 成本分析：烈酒 / 葡萄酒 / 餐食 / 备用金
- 时间维度：天/周/月/年 + 同比对比
- 数据键：依赖 `store.revenue.v1` + `store.petty.v1` 计算

#### 进销存
- 品类：烈酒 / 葡萄酒 / 食材 / 设备 / 日用品（杯具/餐具）
- 每条目：入库/出库/当前库存/预警线
- 数据键：`store.inventory.v1`

## 三、「我的」迁移方案

原 `me` Tab 内容（数据统计/标签管理/备份/设备管理/同步）迁移至：
- **门店 Tab 顶部**：右上角 `person.crop.circle.fill` 图标按钮，点击进入独立 `/me` 页面
- 原 Tab 位置释放给「门店」
- 同步红点角标改为门店 Tab 图标上显示

---

## 四、数据隔离原则

| 数据 | 存储键 | 与其他模块关系 |
|------|--------|--------------|
| 鸡尾酒酒库 | `cocktail.bottles` | 仅鸡尾酒模块使用 |
| 葡萄酒库 | `wine.bottles.v1` | 仅葡萄酒/门店使用 |
| 鸡尾酒自制库 | `cocktail.homemade.*` | 仅鸡尾酒模块使用 |
| 餐食原料库 | `food.ingredients.v1` | 仅餐食/门店使用 |
| 门店在售 | `store.menu.v1` | 引用三个模块数据 |

---

## 五、迁移路径（现有数据不丢失）

| 原位置 | 新位置 | 迁移方式 |
|--------|--------|---------|
| `library` Tab（酒单/酒库/自制库） | `cocktail` Tab | 改名，数据不动 |
| `index` Tab（研发/lab） | `lab` Tab 内研发计划 | 改名，数据不动 |
| `books` Tab | `lab` Tab 内书库 | 嵌入研发 Tab，数据不动 |
| `me` Tab | 门店 Tab 顶部入口 | 改为独立页面，数据不动 |
| 门店酒单（menu）| 门店 Tab 在售清单 | 迁移，数据不动 |
| 采购清单（shopping）| 门店 Tab 采购清单 | 迁移，数据不动 |

---

## 六、开发优先级（分阶段）

**Phase A（框架）**：Tab 重构 + 鸡尾酒/研发/书库迁移（不新增功能，确保现有功能稳定）
**Phase B（新模块）**：葡萄酒库 + 餐食模块（菜单+原料库）
**Phase C（门店升级）**：在售清单 + 采购清单升级 + 「我的」迁移
**Phase D（财务）**：营业状况 + 备用金（A-N分类）
**Phase E（分析）**：经营分析 + 进销存系统
