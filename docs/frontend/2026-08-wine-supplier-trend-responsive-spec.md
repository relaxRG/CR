# 葡萄酒供应商趋势：多端适配与图表/表格切换技术规范

## 1. 适用范围

本规范适用于“葡萄酒 → 总结 → 供应商月度进货趋势”和后续的供应商/酒款采购比较视图。所有显示方式必须使用同一只读比较模型；柱状图、表格、累计视图和下钻不能各自重新计算金额。

## 2. 数据与状态边界

```ts
type TrendViewMode = "bar" | "table";
type TrendMeasure = "monthly_amount" | "cumulative_amount";
type ComparisonPeriod = "previous_month" | "custom_month";

interface WineSupplierTrendUiState {
  viewMode: TrendViewMode;
  measure: TrendMeasure;
  comparisonPeriod: ComparisonPeriod;
  compareMonth?: string;
  selectedSupplierIds: string[];
  selectedMonth: string;
}
```

`selectedMonth`、供应商选择、指标和比较期是唯一 UI 状态。切换柱状图/表格时只变更 `viewMode`，不得重置月份、供应商、比较期、滚动位置或读取新的金额口径。初始累计仅影响各自的累计显示，不能进入当月金额、库存成本或付款金额。

## 3. 布局完整性规则

| 模式 | 典型宽度 | 呈现规则 |
|---|---:|---|
| 紧凑 | iPhone / 窄分屏 | 默认表格；图表仅显示已选供应商，标签可省略并由可访问性文本补全 |
| 常规 | iPad 分屏 / 常规窗口 | 柱状图与比较摘要同区；表格可横向滚动且固定供应商列 |
| 扩展 | iPad 全屏 / macOS 中宽窗口 | 图表和比较表并列；最多显示 6 个供应商，其余进入“其他”但可下钻 |
| 宽屏 | macOS 放大窗口 | 图表、比较摘要和表格三列栅格；不放大字体到破坏行密度 |

禁止用过小字体解决窄宽度。窗口变窄时应优先减少同时显示的供应商、将比较摘要换行或切至表格，而不是截断金额、隐藏筛选或使点击目标消失。系统字体倍率升高时自动增高图表容器和表格行高；字号、轴标签与触控区域都必须在容器内完整显示。

## 4. 图表/表格切换

趋势标题右侧使用分段控件：`柱状图｜表格`。它是显示方式，不是业务筛选。切换后：

1. 保留当前月份、供应商选择、月度/累计指标和比较期；
2. 保留比较模型产生的本期、对比期、差额和百分比；
3. 柱状图点击某供应商，表格切换后自动滚动并高亮同一行；
4. 表格选择供应商，返回柱状图后保留高亮；
5. 无数据时两种模式都显示同一解释性空状态，不伪造零值柱。

## 5. 图表实现规范

- 数据源：`buildWinePurchaseComparison(...)` 或等价只读模型；禁止直接遍历快照或采购数组二次计算。
- 柱颜色：主系列用当前操作色；对比期使用中性灰；正负差只在差额标签中使用语义色，避免图表颜色承载过多含义。
- 金额轴必须明确单位；超过容器宽度时允许水平可访问滚动，不压缩柱宽至不可读。
- Tooltip 显示供应商、当前金额、对比金额、绝对差和百分比；零基数显示“新增”，不显示无穷大百分比。
- 图表不能成为唯一信息来源；表格必须可获得完整数字和排序。

## 6. 表格规范

表格列依次为：供应商、当前金额、对比金额、差额、变化率、累计金额、最后采购日。供应商列固定；金额右对齐；名称使用中英文双行时，英文采用较轻字重并占用受控高度。排序只影响表格行次序，不修改供应商管理的权威排序。

## 7. 多端验收

- macOS 将窗口从窄到宽拖动时，无白屏、重叠、标签消失、筛选重置或柱状图重复请求。
- iPad 50/50 分屏与浮窗下，切换表格/图表保留所有筛选状态。
- iPhone 在最大系统字体倍率下，分段控件、比较摘要和表格操作全部可见可点。
- 柱状图和表格在同一状态下的金额、差额和排序键一致。
- 断网时保留最后成功的只读模型并显示刷新状态；旧请求不得覆盖最新月份选择。
