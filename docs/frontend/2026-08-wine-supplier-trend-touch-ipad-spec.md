# 葡萄酒供应商趋势组件：iPhone 与 iPad 触控交互和响应式布局优化方案

## 一、设计目标

供应商趋势在移动端和 iPad 上必须保持同一比较模型、同一金额口径和同一状态。触控优化不能通过缩小关键文字、隐藏筛选或将图表变成不可操作的装饰来换取空间。

> **柱状图和表格是同一比较结果的两种视图，而不是两套数据或两条交互路径。**

## 二、触控交互规则

| 元素 | 单击 | 长按 | 横向滑动 | 要求 |
|---|---|---|---|---|
| 柱状图柱体 | 选中并显示本期、对比期、差额；再次点击进入供应商采购明细 | 打开操作菜单：查看明细、固定比较、复制金额 | 在图表可滚动时水平浏览供应商 | 触控目标不小于 44pt |
| 供应商表格行 | 高亮并下钻到采购明细 | 打开上下文操作 | 表格横向滚动，不触发行点击 | 供应商名称始终可见 |
| `柱状图｜表格` 分段控件 | 切换显示方式 | 无 | 不适用 | 切换不得重置月份、筛选或比较期 |
| 月份/对比筛选 | 打开选择器 | 无 | 与页面纵向滚动互不冲突 | 选项可在动态字体下完整显示 |
| 图表空白处 | 清除柱体高亮 | 无 | 水平滚动图表 | 不触发意外刷新 |

### 手势优先级

图表容器仅在内容超出可视宽度时接受水平滚动。垂直手势优先交给页面 `ScrollView`；水平位移超过纵向位移且达到 8pt 阈值后，才锁定到图表横向滚动。柱体点击通过 `Pressable` 处理，不能与横向滑动同时触发。

## 三、iPhone 布局

在窄宽度下，组件使用单列顺序：标题和本期摘要、比较摘要、显示方式分段控件、图表或表格、下钻入口。默认推荐表格，因为金额、差额和变化率更容易完整阅读；用户切换到柱状图后保留选择。图表最多显示 3 个柱体，更多供应商进入横向滚动区域；不能将柱宽压缩到少于 56pt。

标题使用 17pt，金额 15–17pt，辅助描述不低于 12pt。供应商名可中英文双行，第二行使用较轻字重；比较差额必须有文字符号和颜色双重表达，不能仅依赖红绿颜色。

## 四、iPad 分屏、浮窗和全屏

| 场景 | 宽度策略 | 图表 | 表格 |
|---|---|---|---|
| 1/3 分屏或浮窗 | 按 iPhone 紧凑模式 | 最多 3 柱，允许横向浏览 | 单列金额，隐藏非关键比较列并可展开 |
| 1/2 分屏 | 常规模式 | 最多 5 柱，图表高度 300pt | 固定供应商列，显示当前/对比/差额 |
| 全屏横向 | 扩展模式 | 最多 6 柱，图表高度 340pt | 图表和表格可并列；仍共享同一筛选状态 |
| Stage Manager 可变窗口 | 根据实时宽度平滑切换 | 不重置选择/滚动/筛选 | 行高随字体倍率增长 |

iPad 上表格不能因空间变大而使用无意义的大留白；优先增加名称展示、比较列和可见供应商数量。窗口缩小时，先减少并列区域和柱数，再转为横向滚动，最后才选择表格回退。

## 五、动态字体和无障碍

系统字体倍率超过 1.15 时，图表高度和行高必须同比增加；x 轴供应商标签改为可访问名称或移入 Tooltip/详情，避免叠压。屏幕阅读器应朗读“供应商、当前金额、对比金额、绝对差、变化状态、是否可下钻”。焦点顺序为标题、比较筛选、显示方式、柱体或表格行、下钻。

## 六、状态保留与错误处理

窗口缩放、旋转、iPad 分屏调整和柱状图/表格切换不得清空：当前业务月、比较月、月度/累计指标、供应商多选、选中供应商和滚动上下文。网络中断时保留最近一次成功比较模型，展示“数据未刷新”状态；旧请求或过期窗口尺寸计算不得覆盖最新状态。

## 七、测试验收

- [ ] iPhone 375pt、430pt、最大动态字体下可完成柱体选择、表格下钻与显示方式切换。
- [ ] iPad 1/3、1/2、全屏及 Stage Manager 连续缩放时没有遮挡、跳变、空白或状态丢失。
- [ ] 柱状图与表格在同一筛选状态下金额、对比差额、供应商排序一致。
- [ ] 横向图表滑动不触发柱体误点；垂直页面滚动不被图表锁死。
- [ ] 屏幕阅读器可以读出差额和“新增”状态；色盲用户不依赖颜色理解变化。
