## 上线后首次业务验收

首次实际切组应由用户在应用中从“设备管理 → 同步组切换 → 加入其他同步组”发起。若当前设备是主设备且原组还有活跃成员，应用会先要求选择新的主设备；原组只有本机时则会给出保留旧组云端数据、但不再保留活跃主设备的确认提示。输入目标组邀请码后，应依次观察：本地快照、写入屏障、目标组完整下载、页面重载和目标组普通同步恢复。

切组期间如遇断网或强制退出，不应清除应用数据或重新进入普通同步；下次启动时系统会根据安全恢复票据继续目标组水合，或在提交前阶段取消准备并恢复原组。

## 回滚步骤

如部署后健康检查失败或出现未预期的Worker异常，请在 Cloudflare Worker 的 **Deployments / Versions** 页面选择 `f7523047` 并执行回滚。回滚只恢复Worker代码，不会自动撤销已经完成的切组事务；若已有事务处于 `committed`，应保留当前目标组成员资格并按日志规范完成恢复，而不能通过回滚将A组数据推送到B组。
