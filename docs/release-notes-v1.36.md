# Cocktail-R 产品更新日志与使用指南 (Build 136)

**发布日期**：2026年8月10日  
**版本号**：Build 136

本次更新聚焦于**员工管理、薪资引擎、多端同步及 UI 交互**的全面重构与体验优化，解决了大量历史遗留问题，并引入了全新的全局排序功能和智能金额显示规范。

---

## 🚀 核心新特性

### 1. 全局员工排序功能
全新的「员工排序」页面取代了原有的拖拽排序，提供更稳定、更清晰的排序体验，并实现了全项目联动。

- **分组顺序自定义**：支持自由调整「前厅/后厨/公司/临时兼职」等分组的先后顺序。
- **员工顺位自定义**：支持在各分组内部通过「↑ ↓」按钮精确调整员工顺位。
- **全项目联动**：排序设置保存后，立即同步应用到**员工管理列表、排班表、薪资统计卡片、考勤概况、编辑薪资页面、月报明细**以及**导出的 Excel/PDF 报表**中。

### 2. 智能金额显示规范
全项目金额展示体验全面升级，告别冗余的小数点和丢失的精度。

- **智能小数位**：整数金额不再显示 `.00`（如 `¥9305`），有小数的金额精确保留两位（如 `¥345.50`）。
- **全域覆盖**：覆盖薪资卡片、编辑薪资、考勤概况、烈酒进销存、葡萄酒库存、财务月报等所有模块。

### 3. 调休余额管理面板重构
考勤概况和薪资统计中的「调休余额管理面板」进行了彻底的逻辑与 UI 拆分，操作更加清晰。

- **三分区设计**：将「加班调休」（橙色）、「节假日换休」（粉色）和「手动调整」（灰色）完全分离。
- **内联展开**：在「考勤概况卡片」中点击「存入/兑换」后，面板直接在卡片底部内联展开，无需跳转页面。
- **数据互通**：所有操作立即同步至底层 Store，各页面数据实时更新。

## 🛠 功能优化与交互升级

### 薪资与考勤体验优化
- **备注功能升级**：编辑薪资页的备注框改为「编辑/保存」模式，防止误触；薪资统计卡片在收起和展开状态下均会在底部显示备注预览。
- **考勤卡片展开还原**：恢复了考勤概况卡片的完整三分区展开布局（出勤统计 / 加班明细 / 节假日明细），无数据时显示优雅的兜底状态。
- **兼职薪资逻辑隔离**：彻底修复了长期兼职员工被错误套用全职逻辑（节假日倍数工资、特殊状态扣薪）的问题。
- **废弃字段清理**：移除了从未被计算引擎使用的 `monthlyFixedSalary`（月度固定薪资）幽灵字段。

### 移动端操作体验
- **防抖保护**：为「导出 Excel/PDF」等高风险耗时操作添加了 1500ms 防抖保护，防止移动端连续快速点击导致重复触发。
- **点击热区扩大**：排序页面的「↑ ↓」按钮尺寸扩大至符合 iOS HIG 规范的 44×44pt，并增加了 `hitSlop` 隐形点击热区，小屏设备操作更顺畅。
- **事件冒泡防护**：修复了 27 处嵌套按钮（如调休面板内的存入按钮）点击时导致外层卡片意外收起的交互 Bug。

## 🐛 核心 Bug 修复

1. **多端同步重新加入 Bug**：修复了设备在「退出同步组」后，输入新配对码无法重新启动同步引擎、始终保持独立状态的严重 Bug。
2. **幽灵考勤数据 Bug**：修复了在排班表中清空某天工时后，底层仍保留空记录，导致考勤概况错误显示「实际到岗 1 天」的问题。系统启动时将自动执行数据迁移脚本，清理所有历史遗留的空记录。
3. **导出菜单关闭 Bug**：修复了点击导出选项时，由于事件冒泡导致 Modal 提前意外关闭的问题。

## 📖 用户使用指南

### 如何设置员工与分组排序？
1. 进入排班页，点击右上角「员工管理」。
2. 在员工管理列表页，点击右上角的「↕ 排序」图标。
3. 在弹出的排序页面中：
   - **分组排序**：点击各部门右侧的「↑ ↓」按钮调整分组先后顺序。
   - **员工排序**：在各分组内，点击员工右侧的「↑ ↓」按钮调整该员工在组内的顺位。
4. 调整完毕后，点击右上角「保存」。所有报表和界面的排序将立即更新。

### 如何管理调休与换休余额？
1. 在排班页右滑进入「考勤概况」或「薪资统计」页面。
2. 展开任意员工卡片，点击底部的「+ 存入/兑换」按钮。
3. 在展开的面板中：
   - **加班调休**：可将当月加班时数存入余额，或按加班时薪兑换现金。
   - **节假日换休**：可查看所有因节假日上班产生的换休天数，并按日薪兑换现金。
   - **手动调整**：店长可直接增减调休天数（不产生金额变动）。

### 为什么兼职员工的薪资计算变了？
本次更新修复了兼职员工（包含长期兼职和临时兼职）错误套用全职计算逻辑的问题。现在兼职员工的薪资**严格按实际工时（或出勤天数）计算**，不再计算「节假日倍数工资」（如国庆节 3 倍），也不再扣除「特殊状态扣薪」（如病假/事假扣薪）。
