## 场景一：「已预支」合并展示验证

### 1.1 薪资统计页（员工卡片）

**步骤：**
1. 进入「门店」→「员工」→「薪资统计」
2. 切换到 2026年3月
3. 展开「子豪 王琪」卡片

| 位置 | 字段名 | 显示值 |
|------|--------|--------|
| 收起状态第2行第2格 | **已预支** | 手动预支 + 备用金已付 合计 |
| 展开状态扣款区 | **已预支** | 同上 |

**验证点：** 所有位置均显示「已预支」，无「预支小计」「备用金已付」「已发」等旧名称。

1. 点击「子豪 王琪」→「编辑薪资」

**预期结果：**
- 收起：「调休兑换 / **已预支** / 应发 / 待发」
- 展开：「已预支」单行（不再分「预支小计」+「备用金已付」两行）

### 1.3 iPhone SE 竖屏截断验证

**步骤：**
1. 在 iPhone SE 模拟器（375pt 宽）上运行

## 场景二：绩效补贴控制字段修复验证（根本原因修复）

### 2.1 正常保存后不被 autoSync 覆盖

**步骤：**
1. 进入「子豪 王琪」→「绩效补贴」
2. 勾选「餐补」✓，确认工作绩效档位，填写业绩实际金额
3. 点击「保存」
4. **立即**返回薪资统计页（不要等待）
5. 再次进入「子豪 王琪」→「绩效补贴」

**预期结果：**
- 步骤5中，餐补仍为勾选状态 ✅
- 工作绩效档位仍为保存的值 ✅
- 业绩实际金额仍为填写的值 ✅
- 薪资统计卡片「综合额外」= 餐补 + 工作绩效 + 业绩绩效 ✅

**之前的 Bug 表现（已修复）：**
- 步骤5中，绩效补贴页显示「未填写」
- 薪资统计卡片「综合额外」只显示 +¥15（仅其他补贴）

### 2.2 切换月份后控制字段不串扰

**步骤：**
1. 在 2026年7月为「子豪 王琪」设置绩效补贴（餐补✓，工作绩效 T1）
2. 切换到 2026年8月
3. 查看「子豪 王琪」的绩效补贴

**预期结果：**
- 8月绩效补贴为空（未设置）
- 返回7月，7月的设置仍然存在
