# 响应式分页规则推广评估

## 结论

排班表的统一响应式分页规则可以推广到系统中所有“逻辑页面切换”或“多级分页”面板，但不应机械套用到横向内容列表、表格、标签和卡片滚动区。是否使用该规则取决于横向滚动是否代表一个完整页面及其分页偏移是否依赖容器宽度。

## 统一可复用工具

`lib/theme/responsive-pager.ts` 提供三项无状态规则：

| 工具 | 职责 |
|---|---|
| `clampPagerIndex` | 将异常、负数和越界逻辑页索引限制在合法范围。 |
| `getResponsivePagerOffset` | 基于**当前**容器宽度计算 `pageIndex × pageWidth` 偏移。 |
| `getResponsivePagerIndex` | 依据当前页宽把滑动停靠偏移解析为合法页索引。 |

所有使用横向 `pagingEnabled` 的页面都应使用这组规则，并在宽度变化后用当前页索引重新对齐。显式页宽的子项必须使用 `flexGrow: 0` 和 `flexShrink: 0`。

## 系统面板分类

| 区域 | 结构 | 风险评估 | 处理结论 |
|---|---|---|---|
| 劳动模块外层三页 | 横向 `pagingEnabled`，完整逻辑页 | 高：曾发生缩放错页 | 已接入统一工具。 |
| 排班表内层两页 | 横向 `pagingEnabled`，嵌套于外层 | 高：曾使用静态宽度 | 已接入统一工具与桌面缩放H5回归。 |
| 烈酒库存 | Tab切换 + 横向数据表 | 中：没有逻辑分页，但曾保留未使用静态宽度快照 | 已删除 `Dimensions.get` 静态宽度，保留表格自身横向浏览。 |
| 书籍阅读器 | 手势翻页/WebView阅读布局 | 低：已使用 `useWindowDimensions`，不是 React Native 横向 `pagingEnabled` 容器 | 保持现有实现；后续改为横向 ScrollView 分页时必须接入统一工具。 |
| 酒款、配方、标签、筛选Chip和卡片横滑区 | 内容滚动，不代表完整逻辑页 | 低：固定页宽会破坏内容浏览 | 不应用分页工具；继续使用内容最小宽度、可收缩文本和局部横滑。 |
| 同步日志 | 横向内容展示 | 低：不是分页 | 不应用；仅维持无根级横向溢出约束。 |

## 自动化回归矩阵

### 纯函数

`tests/responsive-pager.test.ts` 覆盖：

- 负数、异常和越界页索引；
- 零宽度与异常页宽；
- 滑动偏移的半页停靠阈值；
- 连续 1024/1280/1440px 宽度变化时，相同逻辑页按新宽度生成偏移；
- 烈酒库存不允许重引入模块级静态宽度快照。

### 排班源码护栏

`tests/schedule-responsive-pager.test.ts` 覆盖：

- 禁止 `Dimensions.get("window")` 和 `SCREEN_W`；
- 外层三页与内层两页的实时页宽一致；
- 宽度变化后的当前页重对齐；
- 控制栏可换行，避免缩放时压缩日历网格。

### H5视觉回归

`scripts/h5-schedule-correction-e2e.mjs` 连续验证：

- 375/390/430pt移动端；
- 1024/1280/1440px桌面连续宽度变化；
- 外层排班页、内层排班页、内层考勤页均等于当前页面宽度；
- 缩放后保持排班当前页；
- 所有受检页面无根级横向溢出。

## 采用规范

新增完整逻辑页横滑时，必须：

1. 使用实时容器宽度，不读取模块顶层静态 `Dimensions`；
2. 用 `getResponsivePagerOffset` 和 `getResponsivePagerIndex` 处理滚动；
3. 在尺寸变化时恢复当前逻辑页；
4. 为每个分页页提供可测量测试标识；
5. 同时覆盖手机、桌面及连续宽度变化。

不属于完整页面切换的内容横滑区域不得使用这套工具，以避免将数据表、卡片或标签错误约束为整页宽度。
